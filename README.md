# HTML





**Html (Hyper Text Markup Lenguage)** No es el lenguaje de programacion. Es un lenguaje de marcado que usa etiquetas para definir su estructura y el significado del contenido de una pagina.

Piensa en HTML como en los planos de una casa. Los planos de una casa en si, pero definen donde va cada pared, cada puerta o cada ventana. De la misma forma, HTML no define colores,tamaños,ni animacione; *define que es cada elemento y como se relaciona con los demas.* 

HTML funciona con etiquetas **(tags)**
Cada etiqueta se escribe entre corchetes angulares o los símbolos de mayor qué y menor que `<>`, y la mayoría tiene una etiqueta de apertura y otra de cierre:

```html
<h1>Este es un título principal</h1>
<p>Este es un párrafo</p>
<a href="https://google.com"> Este es un enlace </a>
```
## Atributos

Las etiquetas pueden tener atributos que agregan información adicional. En el ejemplo del enlace, href es un atributo que indica hacia dónde dirige el enlace.


Para cerrar una etiqueta, se necesita colocar otra etiqueta, pero con la diferencia de que esta última tiene una diagonal.

Los enlaces requieren de `href` el cuál va en la etiqueta de apertura y por eso es que hay una etiqueta de cierre a mitad del escrito.
